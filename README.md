# ISM Consulting Services – sitio web

Mismo diseño que ismconsultores.com, optimizado para velocidad y desplegado en Railway.
- HTML pre-renderizado + `app.js` precompilado
- Fotos locales en WebP (`img/`) con carga diferida
- `server.js`: servidor sin dependencias con compresión brotli/gzip y caché (`npm start`)
- Formulario que abre WhatsApp con el mensaje listo
